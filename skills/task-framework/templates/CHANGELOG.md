## 记录规范

- 每个 session（或每次连续操作）写一条 `## 日期 时间（含秒）` 记录
- **操作:** 必填，一句话概括
- **原因:** 可选，决策理由
- **改动/问题/解决/结果:** 按需填写
- **素材状态:** 推荐维护，快速知道什么能复用
- **下一步:** 跨 session 必填，新 session 的起点
- 纯命令输出不要写这里（放 `logs/`）
- checklist 勾选不要写这里（放 `TASK.md`）
